  • ความสามารถในการสื่อสารต่ำ - กำลังพยายามพูดคุยกับเพื่อนร่วมงานให้มากขึ้น

นักศึกษาวิศวกรรมไฟฟ้า | ผู้เริ่มต้นเขียนเว็บ

ผมกําลังศึกษาอยู่ชั้นปีที่ 4 สาขาวิศวกรรมไฟฟ้าสนใจงานด้าน เชื่อมโยง ระบบ Hardware Software และระบบ IoT เป็นพิเศษ และกำลังมองหาโอกาสฝึกงานในสายนี้

ติดต่อดิฉัน

จุดแข็งและสิ่งที่กาลังพัฒนา

จุดแข็ง

  • เข้าใจโครงสร้างพื้นฐานของระบบฮาร์ดแวร์และการเชื่อมต่อกับซอฟต์แวร์
  • เปิดรับเทคโนโลยีใหม่ๆ เสมอ และเรียนรู้การใช้เครื่องมือใหม่ได้อย่างรวดเร็ว

สิ่งที่กำลังพัฒนา

  • การนำเสนอเรื่องเทคนิค - กำลังฝึกฝนการอธิบายการทำงานของระบบที่ซับซ้อนให้ผู้อื่นเข้าใจง่ายขึ้น
  • การประยุกต์ใช้ซอฟต์แวร์ - กำลังศึกษาเทคนิคการเขียนสคริปต์ Python และจัดการโครงสร้างข้อมูล JSON ให้มีประสิทธิภาพยิ่งขึ้น

ทักษะเด่น

Python

เขียนสคริปต์จัดการข้อมูล อ่าน-เขียนไฟล์ จัดการการรับส่งข้อมูลผ่าน Serial Port และทำระบบสั่งงานพื้นฐาน

JSON

เข้าใจโครงสร้างข้อมูล JSON สำหรับใช้รับ-ส่งข้อมูลระหว่างซอฟต์แวร์ API และอุปกรณ์ต่างๆ ได้อย่างถูกต้อง

Circuit & Hardware

อ่านแบบวงจร (Schematic) ต่อวงจรทดสอบบน Breadboard และใช้อุปกรณ์วัดพื้นฐานอย่าง Multimeter ในการตรวจเช็กวงจร

C / C++ (Basic)

เขียนโปรแกรมเบื้องต้นสำหรับสั่งงานไมโครคอนโทรลเลอร์ (เช่น Arduino / ESP32) เพื่อเชื่อมต่อกับเซนเซอร์ต่างๆ
